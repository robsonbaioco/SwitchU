Put a 1280x720 `cover.jpg` (or `.png`) here.

It is what the Installed tab shows for the theme. Without it the theme still
works -- it is listed without a picture. The menu also finds a cover with no
manifest entry at all, if it is named `preview/cover.png`, `preview/cover.jpg`,
`preview/screenshot.png`, `preview/screenshot.jpg` or `cover.png`.
