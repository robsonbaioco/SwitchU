A Joy-Con held sideways
- A single Joy-Con can now confirm: SwitchU asks the system for the sideways orientation, the way the console's own menu does, which is what turns the four direction buttons into A/B/X/Y. Half of a pair that is still registered as a pair has no action buttons either way -- register it on its own in Change Grip/Order, with SL+SR.

Any player's controller
- The menu read player 1 and handheld mode only. It now reads all eight player slots.

Change Grip/Order
- It no longer opens with player 1 already taken by the controller that opened it, so the order can actually be redone. The controller settings the applet is given are published properly now, so a lone Joy-Con can be registered there.
--pt-BR--

Um Joy-Con na horizontal
- Um Joy-Con sozinho agora consegue confirmar: o SwitchU pede ao sistema a orientação horizontal, como faz o menu do console, que é o que transforma os quatro direcionais em A/B/X/Y. A metade de um par ainda registrada como par não tem botões de ação de todo jeito -- registre-a sozinha no Mudar a Ordem, com SL+SR.

O controle de qualquer jogador
- O menu lia só o jogador 1 e o modo portátil. Agora lê os oito lugares de jogador.

Mudar a Ordem
- Deixa de abrir com o jogador 1 já ocupado pelo controle que o abriu, então a ordem pode de fato ser refeita. As definições de controle entregues ao applet agora são publicadas como devem, e um Joy-Con sozinho pode ser registrado ali.
