One restart to install an update
- The menu now puts the new daemon in place before the restart, so the console comes up already running it and unpacks the rest from there. Updates used to leave the daemon a release behind the menu until a second boot. Installing this release still takes two restarts, because the code installing it is the old one.

Which build is running
- The daemon writes its version in the log at startup, and the menu's log is kept for hours instead of five menu restarts, so a bug reported later still has a log behind it.

Um reinício para instalar um update
- O menu passa a colocar o daemon novo no lugar antes do reinício, então o console já sobe rodando ele e desempacota o resto dali. Antes, um update deixava o daemon uma versão atrás do menu até um segundo boot. Instalar esta versão ainda leva dois reinícios, porque quem instala é o código antigo.

Qual build está rodando
- O daemon escreve a versão dele no log ao iniciar, e o log do menu passa a durar horas em vez de cinco reinícios do menu, então um bug relatado depois ainda tem log por trás.
