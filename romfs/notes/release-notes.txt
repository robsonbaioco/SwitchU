A backup that survives a clean install
- At every boot SwitchU copies its configuration, themes and artwork to backup/SwitchU, which a pack's clean install leaves alone. If the configuration ever goes missing, it is restored before the menu starts, so you come back to your settings instead of the tutorial.
- A firmware update through the CNX Updater still switches SwitchU off: open SwitchU Manager and use Update or Repair installation to bring it back.

Renaming a game
- A game renamed because it had no name of its own is now searched on SteamGridDB by the new name right away, instead of only after the menu restarted.

Um backup que sobrevive à instalação limpa
- A cada boot o SwitchU copia a configuração, os temas e as artes para backup/SwitchU, que a instalação limpa de um pack não apaga. Se a configuração sumir, ela é restaurada antes de o menu abrir, e você volta às suas configurações em vez do tutorial.
- Uma atualização de firmware pelo CNX Updater continua desligando o SwitchU: abra o SwitchU Manager e use Update ou Repair installation para trazê-lo de volta.

Renomear um jogo
- Um jogo renomeado por não ter nome próprio agora é buscado no SteamGridDB pelo nome novo na hora, e não só depois de o menu reiniciar.
