Updating from SwitchU Manager
- Updates started from SwitchU Manager failed and rolled back, because the Manager held its own file open. It now lets go of it before installing, so updates and the repair added in 2.5.7 go through. With SwitchU running, update from this Update tab instead: the menu holds its own files open, and the Manager is for when SwitchU is off or missing.
--pt-BR--

Atualizar pelo SwitchU Manager
- Updates iniciados pelo SwitchU Manager falhavam e eram desfeitos, porque o Manager mantinha o próprio arquivo aberto. Agora ele solta o arquivo antes de instalar, então os updates e o reparo que entrou na 2.5.7 vão até o fim. Com o SwitchU rodando, atualize por esta aba Update: o menu mantém os próprios arquivos abertos, e o Manager é para quando o SwitchU está desligado ou faltando.
