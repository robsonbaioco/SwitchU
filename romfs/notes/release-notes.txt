Play offline
- New in the game dossier: Play offline. A marked game starts with the console's internet off and the internet comes back when it closes. Bluetooth stays on, so controllers keep working.

Fixes
- Vibration in Settings > Controllers follows the console's own on/off switch.
- Rename now always changes the SteamGridDB search term.
- The Theme Shop reads ncarvalho99's GitHub mirror (8 themes that download) instead of his server, which refuses downloads.

Jogar sem internet
- Novo no dossiê do jogo: Jogar sem internet. Um jogo marcado abre com a internet do console desligada, e a internet volta quando ele fecha. O Bluetooth continua ligado, então os controles funcionam.

Correções
- A Vibração em Configurações > Controles segue o interruptor liga/desliga do próprio console.
- Renomear agora sempre muda o termo de busca do SteamGridDB.
- A Loja de Temas lê o espelho do ncarvalho99 no GitHub (8 temas que baixam) em vez do servidor dele, que recusa downloads.
